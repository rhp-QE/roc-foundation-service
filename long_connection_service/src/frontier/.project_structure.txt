WebSocket 长连接服务项目结构
=====================================

frontier/
├── connection.go           # 单个WebSocket连接的封装
├── message.go             # 消息结构定义和验证
├── hub.go                 # 消息分发中心和连接管理
├── handler.go             # HTTP和WebSocket处理器
├── server.go              # 服务器主入口
├── config.go              # 配置结构和默认值
├── example_test.go        # 示例代码和单元测试
├── README.md              # 完整文档
├── QUICKSTART.md          # 快速开始指南
├── client_example.html    # 浏览器测试客户端
├── main/
│   └── main.go           # 服务启动入口
└── scripts/
    ├── build.sh          # 构建脚本
    └── run.sh            # 运行脚本

核心组件说明
=============

1. connection.go (连接管理)
   - Connection 结构：封装单个WebSocket连接
   - ReadPump：处理消息接收
   - WritePump：处理消息发送
   - 元数据管理
   - 心跳和活跃状态检查

2. message.go (消息处理)
   - Message 结构：统一消息格式
   - 消息类型定义（auth, heartbeat, chat, notify, error, ack, broadcast）
   - 消息验证
   - 数据访问辅助方法

3. hub.go (中心调度)
   - Hub 结构：管理所有连接
   - 连接注册/注销
   - 消息路由和分发
   - 心跳检查
   - 统计信息收集
   - 自定义消息处理器注册

4. handler.go (请求处理)
   - WebSocketHandler：处理WebSocket连接升级
   - StatsHandler：提供统计信息API
   - HealthHandler：健康检查API
   - 内置消息处理器（认证、聊天、广播）

5. server.go (服务器)
   - Server 结构：服务器主控制器
   - 启动/停止服务
   - 路由注册
   - 组件集成

6. config.go (配置)
   - Config 结构：服务配置
   - 默认配置
   - 配置验证

API 端点
========

- ws://localhost:8080/ws?user_id={user_id}  # WebSocket连接
- http://localhost:8080/health              # 健康检查
- http://localhost:8080/stats               # 统计信息

快速启动
========

1. 安装依赖
   cd /root/project/imcloud/roc-foundation-service
   go mod tidy

2. 启动服务
   cd long_connection_service/src/frontier
   ./scripts/run.sh

3. 测试连接
   用浏览器打开 client_example.html

技术栈
======

- Go 1.22.2
- gorilla/websocket (WebSocket实现)
- google/uuid (唯一ID生成)
